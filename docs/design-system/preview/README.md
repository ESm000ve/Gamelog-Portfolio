# Offline design-system viewer

Open `index.html` in a browser with the complete `preview/` folder beside it. Alternatively, from the project root run `node docs/design-system/serve-preview.mjs` and open the printed address.

The viewer includes the 10 macOS Figma presentation boards and the CSS/JSON token snapshots. Search boards, step through them and download individual PNGs. It reads no personal library and saves nothing.

[Open the editable Figma design system](https://www.figma.com/design/TiuL5F9dS9HemUafC0ZnIM?node-id=2-2) · [Portfolio board](https://www.figma.com/design/TiuL5F9dS9HemUafC0ZnIM?node-id=2-687)

These are reference exports. The editable components and variables remain in Figma; no native `.fig` file is included. Figma access follows the file owner’s sharing settings. Read [handoff notes](FIGMA-HANDOFF.md) for scope and limits.
